Weather Forecast App 🌤️

This is a simple weather forecast application created with Flutter and Dart.

The project was created as a learning project to practice Flutter widgets, layouts, and UI design.

Features

🔎 Search field for entering a city name
🌍 Shows the location
📅 Shows the current date
☀️ Shows weather condition
🌡️ Shows temperature
💨 Shows wind speed
💧 Shows humidity
☁️ Shows cloud percentage
📆 Shows a 7-day weather forecast
↔️ Horizontal scrolling for the forecast
